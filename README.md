🌷 نوروزی (Nowroozi)

داشبورد جشن نوروز — شمارش معکوس تا تحویل سال، تقویم شمسی، فال حافظ و هفت‌سین؛ همه در یک اپ React خفن! 🎉



✨ امکانات

⏳ شمارش معکوس نوروز — لحظه‌به‌لحظه تا تحویل سال، با انیمیشن نرم

📅 تاریخ شمسی — تبدیلگر میلادی ➡️ جلالی، با اعداد فارسی

🪶 فال حافظ — نیت کن، فال بگیر و تعبیر رو بخون

🪴 هفت‌سین تعاملی — سبزه، سیب، سمنو و… با توضیح هر سین

🎨 UI راست‌چین (RTL) با تم شب نوروزی و انیمیشن‌های Framer Motion

📱 ریسپانسیو — از موبایل تا دسکتاپ
